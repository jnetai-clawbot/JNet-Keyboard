# J~Net Keyboard - Changes Log

## 2026-08-15 - v1.0.4
### Changes
- Centered shift row (2nd row from bottom) with 3%p horizontal gap to match other rows
- Added many new unicode fonts: Double Underline, Overline, Double Overline, Slashed, Dotted, Diaeresis, Tilde, Tilde Below, Macron, Acute, Grave, Circumflex, Caron, Breve, Ring, Cedilla, Ogonek, Comma, Negative Squared, Zalgo, Halfwidth, Tiny
- Enter key icon now rendered larger (same size as settings cog) via custom KeyboardView
- Enter key now sends the Enter key event (like pressing enter) instead of inserting a newline
- Fixed "Check for Updates" button to open the GitHub latest release page directly
- About section now shows version v1.0.4

## 2026-08-14 - v1.0.2
### Bug Fixes
- Fixed crash: onCreateCandidatesView() was returning a view already attached to root layout
  (caused "view already has a parent" crash). Now creates a fresh unattached LinearLayout.
- Added LAUNCHER category to manifest so app appears in launcher as both app and keyboard

### Changes
- Auto-correct/suggestions now disabled by default (toggle in General settings)
- onDisplayCompletions() respects auto-correct setting before showing suggestion bar

## 2026-08-14 - v1.0.1
### Changes
- Fixed bottom row centering: space bar widened to 32%p, added settings cog (⚙) to bottom right
- Removed horizontal gaps between all keys (0px) for tighter layout
- Removed trailing horizontalGap on 'l' key in A-row to eliminate gap between k and l
- Fixed backspace: now uses sendDownUpKeyEvents(KEYCODE_DEL) for reliable single-press deletion
- Added CandidateView suggestion bar for auto-correct/word completion support
- Keyboard layout now wrapped in LinearLayout with CandidateView above KeyboardView

### Implementation Summary
- Complete Android IME keyboard service (InputMethodService)
- UK QWERTY and US QWERTY keyboard layouts with number row
- 26 Unicode style transformations (Bold, Italic, Script, Fraktur, Sans-Serif, Monospace, Double-Struck, Small Caps, Superscript, Subscript, Bubble, Square, Fullwidth, Inverted, Strikethrough, Underline, etc.)
- Translation system with LibreTranslate and Google Translate providers
- Secure input detection (passwords, PINs disabled for translation/transformation)
- Settings with persistence (SharedPreferences)
- Dark/Light/System theme support
- Emoji database with search (100+ emojis)
- Symbol database with categories (Punctuation, Math, Currency, Arrows, Greek, etc.)
- Clipboard manager (save/load text across apps)
- Key remapping system
- Update checker (GitHub API)
- About section with share functionality
- Comprehensive diagnostics system with error codes
- GitHub Actions CI/CD workflow for signed release builds
- Permanent keystore (ciphervault alias from password vault)
- minSdk 26 (Samsung Galaxy S8), targetSdk 34
